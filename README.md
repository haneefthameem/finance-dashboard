# Personal Finance Dashboard

A personal finance dashboard project using HTML, JavaScript, XAMPP, PHP, and MySQL.

## Features
- Bank account tracking
- Salary analysis
- Stock portfolio tracking
- Gold assets management
- Loan tracking
- Seetu management
- Charts and analytics

---

## Local Setup (XAMPP)

### 1. Install XAMPP
Download:
https://www.apachefriends.org/

### 2. Start Services
Open XAMPP Control Panel:
- Start Apache
- Start MySQL

### 3. Move Project
Copy this project folder into:

C:/xampp/htdocs/

Example:
C:/xampp/htdocs/personal-finance-dashboard

### 4. Import Database
- Open:
http://localhost/phpmyadmin
- Create database:
finance_dashboard
- Import:
finance_dashboard.sql

### 5. Run Project
Open browser:
http://localhost/personal-finance-dashboard
